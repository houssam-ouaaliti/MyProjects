# MyProjects

Software engineering student portfolio by **Houssam Ouaaliti**: full-stack web applications, algorithms and team projects, in Java, Python, PHP and JavaScript.

I am looking for a **final-year internship (PFE)** and for freelance missions. Feel free to open an issue or get in touch through my GitHub profile.

## Projects

| Project | Stack | What it is |
|---------|-------|------------|
| [**Multiplayer Card Game**](jeu-cartes-multijoueurs/) | Java 17, Spring Boot, WebSocket, React, MySQL, Docker | Real-time UNO-style game for 2 to 4 players with lobby, chat and global ranking |
| [**Property Booking Platform**](laravel/laravel-test/) | PHP 8.2, Laravel 12, Breeze, Tailwind CSS | Authenticated back-office to manage properties and bookings |
| [**Mastermind**](Mastermind/) | Python, Tkinter, NumPy, Matplotlib | Codebreaker and codemaker strategies with performance analysis and a GUI (school project, pair) |
| [**2D Puzzle Game**](2D-Puzzle-Game/) | Java, Swing / AWT | 2D puzzle game inspired by *It Takes Two* (school project, team of 8) |
| [**Rubik's Cube Solver**](Rubiks_cube/) | Python, OpenCV, VPython | 2D and 3D cube solving with colour detection and 3D visualisation |

## Skills

- **Backend**: Java, Spring Boot, JPA / Hibernate, REST APIs, WebSocket, PHP / Laravel
- **Frontend**: React, Vite, Tailwind CSS
- **Data and tooling**: MySQL, Docker, Docker Compose, Jenkins, Git, Maven, JUnit
- **Algorithms**: search strategies, constraint reduction, solver design in Python
